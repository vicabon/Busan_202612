# 韓國釜山2026年12月自由行全方位指南：4日分區行程 ・ 住宿評比 ・ 百大美食 (README.md)

本專案專為 **2026年12月3日 ～ 12月8日（6天5夜，扣除首尾交通共 4 個完整遊玩日：12/4 ～ 12/7）韓國釜山雙人自由行** 規劃，完整整合三大主軸：
1. **🗓️ 行 (Itinerary - 12/4~12/7 四日分區行程)**：將 16 個精選必去景點依照地理區域、營業日與公休限制，劃分為 **4 大不折返生活圈**，並串聯周邊順遊景點與藍絲帶名店。
2. **🏨 住 (Hotel - Agent)**：跨 5 大平台（Agoda, Booking, Trip.com, Tripadvisor, Google Maps）大數據住宿評比、價格比對與加權平均口碑（支援凍結窗格與點擊欄位升降排序）。
3. **🍽️ 食 (Food - 100 Great Places)**：釜山觀光公社官方評選 **100 Great Places to Eat in Busan**，標記 **Blue Ribbon Survey (藍絲帶美食調查評級)**、中英韓三語店名、Google Map 一鍵導航與飲食種類。
